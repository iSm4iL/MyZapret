# MyZapret

A Windows x64 interface for managing winws and winws2 profiles, checking connectivity, and restoring previous settings.

- Extract or clone the entire directory into a permanent location.
- Open MyZapret.exe with administrator rights. Choose a profile and click «Применить и проверить».
- The report distinguishes website access, YouTube media retrieval and Discord voice observations. Matchmaking and playback should be verified in the actual client.
- VPN automation follows VPNUS. Service startup can be configured separately in the app.

This revision handles a stale VPNUS connection record when the service has stopped. Driver recovery can also recognise a byte-identical WinDivert driver from the adjacent legacy installation after checking for active users.

Third-party terms are in licenses and docs. Local state and diagnostic captures are excluded from version control.
