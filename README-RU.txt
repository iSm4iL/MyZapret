MYZAPRET — СОБСТВЕННАЯ СБОРКА НА WINWS2

Откройте MyZapret.exe. Движок — winws2, локально собранный ранее из
официальных исходников bol-van/zapret2 (8283f4cd76f6eb55dfc424eb63483bcd16ad7f5c).
Это не заново написанный нами сетевой движок: наши здесь интерфейс, конструктор,
составление конфигураций, проверки и варианты стратегий.

СТРУКТУРА
general (*.bat) — применить целую выбранную стратегию без конструктора.
                  Меняет базу и сбрасывает доноров в черновике; требует VPN OFF.
bin — локально собранный winws2 и необходимые библиотеки/драйвер.
lua — оригинальные Lua-функции zapret2.
lists — списки доменов и сетей.
strategies — редактируемые JSON-рецепты: Tls, QuicRepeats, описание происхождения.
app — код интерфейса и управления.
data — черновик, активный состав, резерв состояния служб и фиксированные releases.
reports — результаты проверок и сравнение исходных сборок.
docs — лицензия и официальный мануал движка.

ПОРЯДОК РАБОТЫ
1. «Показать» фильтрует таблицу. «Проверить» задаёт охват тестов; по умолчанию — все 17 сервисов. Перед сетевыми тестами отключите VPN самостоятельно.
2. «Проверить все ALT» временно запускает доноров ПО ОЧЕРЕДИ.
   После теста восстанавливается прежнее состояние. Победитель сам не применяется.
3. Выберите ячейку справа, нажмите «Взять ... в черновик».
4. «Применить / запустить» запускает службу myzapret2 и сохраняет активный состав.
5. Убедитесь в работе нужного приложения, затем при желании включите автостарт.
6. «Прежний zapret» восстанавливает состояние служб до применения MyZapret.

«Отключить старые zapret» отдельно останавливает службы zapret, zapret2,
zapret-custom и отключает их автозапуск и старые автозадачи. MyZapret продолжает
работать. Файлы сохраняются; исходное состояние восстанавливается кнопкой
«Прежний zapret». Отключение доступно и при включённом VPN.

Изменение базы сбрасывает выбранных доноров. Перенос одного сервиса сохраняет
остальных. Профили сервиса стоят перед общими профилями, чтобы перехватывать
только соответствующие домены. И TCP, и QUIC переносятся из одного рецепта.
Правила winws и winws2 напрямую не смешиваются: здесь все рецепты в Lua-формате.
При изменении JSON запустите панель заново и повторите тесты.

YOUTUBE
Видео проверяется автоматически, без поиска внутренней ссылки вручную.
По умолчанию используется открытый ролик Big Buck Bunny (aqz-KE-bpKQ).
Во время теста каждой стратегии официальный yt-dlp получает прямой HTTPS-поток,
после чего curl скачивает до 256 КБ. Проверяются код ответа, размер и MIME video/.
Адрес успешно полученного потока временно используется в пределах одного теста;
при сбое он запрашивается заново. Между отдельными запусками адрес не сохраняется.

«Ролик для теста…» принимает обычную ссылку YouTube. Пустое поле возвращает
тестовый ролик по умолчанию. Старые ручные googlevideo-ссылки также поддерживаются.
При невозможности определить поток показывается «видео не проверено», а причина
содержится в подсказке ячейки и отчёте. Такой результат не считается успешным.
Зелёный YouTube требует и страниц, и настоящего видеофрагмента.
Это тест передачи видеоданных по TCP/IPv4, а не полного браузерного плеера,
аудиодорожки, QUIC или всех CDN-узлов. YouTube может отдельно требовать авторизацию;
программа не читает cookies браузера и не входит в аккаунт.

Зависимость: официальный yt-dlp 2026.10.26, bin/yt-dlp.exe.
Источник: https://github.com/yt-dlp/yt-dlp/releases/tag/2026.10.26
SHA-256 сверена с опубликованным SHA2-256SUMS; запись — docs/video-probe-dependency.json.
Используется уже установленный Node.js. Полный ролик и ffmpeg не скачиваются.

Таблицы обновляют результаты без удаления существующих строк и сохраняют
выделение, вертикальную и горизонтальную прокрутку.

ИГРЫ
Game Filter + IPSet включают дополнительные профили TLS и распознаваемых UDP
протоколов на портах 1024–65535 для сетей из lists/game-ipset.txt.
Это не обещание исправить любой игровой протокол. Сайты EA/PUBG/Warzone и т.д.
не подтверждают вход, матчмейкинг и соединение с игровым сервером.
Фильтры сначала сохраняются в черновик, затем требуется применение.
Сброс Game + IPSet сохраняет доноров остальных сервисов.

Папку не переносите после установки службы: активные команды содержат абсолютные пути.
Системные hosts, DNS, настройки VPN и Defender эта сборка не меняет.
Старая папка zapret2-lab сохранена как история разработки и возможность возврата.

ЧЕМ ОТЛИЧАЮТСЯ СТРАТЕГИИ
Это набор кандидатов для сравнения, а не десять гарантированно рабочих вариантов.
01: разбиение TLS; 02/03: фейк + разбиение с разными TCP-изменениями;
04: фейк с TCP MD5 + перестановка частей; 05/06: перекрытие 681/568 байт;
07/10: поддельный hostname с разными TCP-изменениями;
08: два фейка + разбиение; 09: фейк + перестановка частей.
Также различается число QUIC-фейков. Конкретные параметры находятся в strategies.

В GANWO 48 готовых сочетаний параметров по нескольким профилям. Это не 48
независимых новых алгоритмов. Например, YouTube-профили ALT12 и ALT13 используют
одинаковый hostfakesplit с TS, но в ALT12 дополнительно задан ip-id=zero.
Наш конструктор позволяет выбирать разные рецепты по сервисам, однако такая
гибкость сама по себе не делает десять рецептов полным аналогом всех 48 GANWO.
Перенесены отдельные идеи; это адаптации, а не точные копии каждой BAT-стратегии.
VPN-АВТО
Кнопка «VPN-авто» включает/выключает фоновую задачу MyZapret-VPN-follow.
При подключении VPNUS MyZapret останавливается; при отключении VPNUS снова
запускается сохранённый ПРИМЕНЁННЫЙ состав, а не черновик. Интервал — 3 секунды.
Это работает при закрытой панели, через задачу Windows от SYSTEM при старте ПК.
Состояние VPN определяется по журналу VPNUS; другие VPN этой функцией не отслеживаются.
Программа не подключает VPN сама. «Стоп» отменяет автоматическое возобновление
до следующего применения или повторного включения VPN-авто.
После перезагрузки учитывается настройка автостарта службы: ручной запуск не
превращается в автоматический. При неизвестном состоянии VPN служба не запускается.
Во время применения и тестов фоновый переключатель уступает управление панели.

ДИАГНОСТИКА YOUTUBE / DNS
Кнопка запускается с отключённым VPN на текущем работающем составе. Она сравнивает
обычный DNS с Google DoH и соединение с полученными IP через временный curl --resolve.
DNS Windows, роутера и браузера не меняются. Подробный JSON и HTML лежат в reports.
Разные адреса CDN сами по себе нормальны и не доказывают подмену DNS.
Новые тесты видео сохраняют hostname CDN, IP и время этапов DNS/TCP/TLS
в video-network.jsonl каждого отчёта, без подписанного URL видеопотока.
СРАВНИТЬ СТАРЫЙ / НОВЫЙ YOUTUBE
Отключите VPN и нажмите кнопку в блоке запуска. Проверяются: без zapret,
применённый MyZapret, сохранённый старый состав, старый ALT11 и ALT11 из GANWO.
Для всех вариантов используется один видеопоток и один закреплённый IP, плюс
отдельная попытка TCP-соединения с ним. Чужие BAT не запускаются: читаются только
параметры. После сравнения восстанавливается прежнее состояние служб; выбор
постоянной стратегии не меняется. Во время проверки старые автозадачи приостановлены.
«Прежний zapret» отдельно возвращает сохранённые старые службу и автозадачи.
ПОЛНОЕ ВОССТАНОВЛЕНИЕ YOUTUBE
Кнопка собирает TLS/QUIC/IPv6/DoH/CDN и расширенный перебор в один запуск.
Описание, условия автоприменения и отмены — docs/FULL-RECOVERY-RU.txt.
